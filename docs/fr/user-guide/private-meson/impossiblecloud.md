# Impossible Cloud (Meson privé)

Identifiant fournisseur dans Electros : **`impossiblecloud`**.

## État

Un guide pas à pas pour créer les identifiants Impossible Cloud n’est pas encore publié.

En attendant :

1. Dans la console Impossible Cloud, créez des identifiants API pour un compte qu’Electros peut utiliser.
2. Conservez clés et secrets en sécurité.
3. Dans Electros : **Connections** → **Add Provider** → **Private** → **Impossible Cloud**, saisissez un **Target name**, remplissez le formulaire d’identifiants, puis **Conclude**.
4. Activez la cible dans **Active Connections**.

Traitez chaque valeur comme un secret. N’envoyez pas les identifiants par e-mail ou chat.
