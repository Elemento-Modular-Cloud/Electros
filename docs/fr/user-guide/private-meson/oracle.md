# Oracle Cloud (Meson privé)

Identifiant fournisseur dans Electros : **`oracle`**.

## État

Un guide pas à pas pour créer les identifiants Oracle Cloud n’est pas encore publié.

En attendant :

1. Dans la console Oracle Cloud, créez des identifiants API (ou un utilisateur/clé API adaptés) pour un compte qu’Electros peut utiliser.
2. Conservez clés, empreintes et identifiants de tenancy en sécurité.
3. Dans Electros : **Connections** → **Add Provider** → **Private** → **Oracle Cloud**, saisissez un **Target name**, remplissez le formulaire d’identifiants, puis **Conclude**.
4. Activez la cible dans **Active Connections**.

Traitez chaque valeur comme un secret. N’envoyez pas les identifiants par e-mail ou chat.
