# Wasabi (Meson privé)

Identifiant fournisseur dans Electros : **`wasabi`**.

## État

Un guide pas à pas pour créer les identifiants Wasabi n’est pas encore publié.

En attendant :

1. Dans la console Wasabi, créez des identifiants API pour un compte qu’Electros peut utiliser pour le stockage objet.
2. Conservez la clé d’accès et le secret en sécurité.
3. Dans Electros : **Connections** → **Add Provider** → **Private** → **Wasabi**, saisissez un **Target name**, remplissez le formulaire d’identifiants, puis **Conclude**.
4. Activez la cible dans **Active Connections**.

Traitez chaque valeur comme un secret. N’envoyez pas les identifiants par e-mail ou chat.
