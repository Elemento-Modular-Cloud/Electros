# Guide utilisateur Electros

Utilisez ce guide comme vous utilisez le produit. Chaque chapitre explique une page de la barre latérale : ce que vous regardez, ce que font les boutons, comment créer des ressources sur cette page, et quand vous arrêter.

Nouveau dans l'application ? Commencez par [Premiers pas](/fr/user-guide/01-getting-started) — cela inclut [comment fonctionne la création](/fr/user-guide/01-getting-started#comment-fonctionne-la-creation) (formulaire → Continue → hôte → Create).
