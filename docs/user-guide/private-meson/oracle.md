# Oracle Cloud (private Meson)

Provider id in Electros: **`oracle`**.

## Status

A step-by-step credential creation guide for Oracle Cloud is not published yet.

Until it is available:

1. In the Oracle Cloud console, create API credentials (or a suitable user/API key) for an account that Electros may use.
2. Keep keys, fingerprints, and tenancy identifiers safe.
3. In Electros: **Connections** → **Add Provider** → **Private** → **Oracle Cloud**, enter a **Target name**, fill the credential form, then **Conclude**.
4. Enable the target on **Active Connections**.

Treat every value as a secret. Do not send credentials by email or chat.
