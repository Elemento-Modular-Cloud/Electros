# Private Meson credentials

A **private Meson** lets your organisation use its own cloud account (bring your own credentials) instead of a shared public Meson demo.

You register the account once under [Connections](../04-connections) → **Add Provider** → **Private**, then enable it on [Active Connections](../03-my-clouds) when you need it.

## What this page is for

These guides explain how to create the provider credentials Electros asks for. Pick your cloud, follow the steps in that console, then paste the values into the Electros form. Treat every key and secret as confidential.

## How to connect in Electros

1. Open **Connections** → Targets → **Add Provider**.
2. Choose **Private**.
3. Select **one** provider.
4. Enter a **Target name**.
5. Fill the credential fields (see the guide for that provider below).
6. **Conclude**.
7. On **Active Connections**, enable the new target (or a scenario that includes it).
