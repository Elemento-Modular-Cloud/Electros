# Wasabi (private Meson)

Provider id in Electros: **`wasabi`**.

## Status

A step-by-step credential creation guide for Wasabi is not published yet.

Until it is available:

1. In the Wasabi console, create API credentials for an account that Electros may use for object storage.
2. Keep the access key and secret key safe.
3. In Electros: **Connections** → **Add Provider** → **Private** → **Wasabi**, enter a **Target name**, fill the credential form, then **Conclude**.
4. Enable the target on **Active Connections**.

Treat every value as a secret. Do not send credentials by email or chat.
