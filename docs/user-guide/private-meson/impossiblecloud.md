# Impossible Cloud (private Meson)

Provider id in Electros: **`impossiblecloud`**.

## Status

A step-by-step credential creation guide for Impossible Cloud is not published yet.

Until it is available:

1. In the Impossible Cloud console, create API credentials for an account that Electros may use.
2. Keep keys and secrets safe.
3. In Electros: **Connections** → **Add Provider** → **Private** → **Impossible Cloud**, enter a **Target name**, fill the credential form, then **Conclude**.
4. Enable the target on **Active Connections**.

Treat every value as a secret. Do not send credentials by email or chat.
