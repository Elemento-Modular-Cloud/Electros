# Electros user guide

Use this guide the way you use the product. Each chapter explains one sidebar page: what you are looking at, what the buttons do, how to create resources on that page, and when to stop.

New to the app? Start with [Getting started](/user-guide/01-getting-started) — it includes [how creation works](/user-guide/01-getting-started#how-creation-works) (form → Continue → host → Create).
