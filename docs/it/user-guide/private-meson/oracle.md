# Oracle Cloud (Meson privato)

Id provider in Electros: **`oracle`**.

## Stato

Una guida passo passo per creare le credenziali Oracle Cloud non è ancora pubblicata.

Finché non sarà disponibile:

1. Nella console Oracle Cloud, crea credenziali API (o un utente/API key adeguati) per un account che Electros può usare.
2. Conserva chiavi, fingerprint e identificativi tenancy in modo sicuro.
3. In Electros: **Connections** → **Add Provider** → **Private** → **Oracle Cloud**, inserisci un **Target name**, compila il modulo credenziali, poi **Conclude**.
4. Abilita il target in **Active Connections**.

Tratta ogni valore come un segreto. Non inviare credenziali via email o chat.
