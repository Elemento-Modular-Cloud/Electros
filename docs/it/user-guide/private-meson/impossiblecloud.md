# Impossible Cloud (Meson privato)

Id provider in Electros: **`impossiblecloud`**.

## Stato

Una guida passo passo per creare le credenziali Impossible Cloud non è ancora pubblicata.

Finché non sarà disponibile:

1. Nella console Impossible Cloud, crea credenziali API per un account che Electros può usare.
2. Conserva chiavi e secret in modo sicuro.
3. In Electros: **Connections** → **Add Provider** → **Private** → **Impossible Cloud**, inserisci un **Target name**, compila il modulo credenziali, poi **Conclude**.
4. Abilita il target in **Active Connections**.

Tratta ogni valore come un segreto. Non inviare credenziali via email o chat.
