# Wasabi (Meson privato)

Id provider in Electros: **`wasabi`**.

## Stato

Una guida passo passo per creare le credenziali Wasabi non è ancora pubblicata.

Finché non sarà disponibile:

1. Nella console Wasabi, crea credenziali API per un account che Electros può usare per l’object storage.
2. Conserva access key e secret key in modo sicuro.
3. In Electros: **Connections** → **Add Provider** → **Private** → **Wasabi**, inserisci un **Target name**, compila il modulo credenziali, poi **Conclude**.
4. Abilita il target in **Active Connections**.

Tratta ogni valore come un segreto. Non inviare credenziali via email o chat.
